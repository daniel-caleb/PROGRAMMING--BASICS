# HTML Fundamentals Lab 2

## Task Title
Create a Student Portfolio Webpage

---

# Objective

This practical task is designed to test your understanding of fundamental HTML concepts including:

- HTML document structure
- Headings
- Paragraphs
- Text formatting elements
- Links
- Images
- Lists
- Tables
- Forms
- Semantic elements

---

# Task Instructions

Create a webpage called:

```bash
portfolio.html
```

Your webpage should contain the following sections and elements.

---

# 1. HTML Document Structure

Your webpage must include:

```html
<!DOCTYPE html>
<html>
<head>
<body>
```

Inside the `<head>` section:

- Add a page title.
- Add meta charset.

Example:

```html
<meta charset="UTF-8">
<title>Student Portfolio</title>
```

---

# 2. Header Section

Create a header section containing:

- Main heading (`h1`)
- A short welcome paragraph

The heading should display:

```text
My Portfolio
```

---

# 3. About Me Section

Create a section titled:

```text
About Me
```

Include:

- At least 2 paragraphs about yourself
- Your course/program
- Career interests
- Hobbies

Use the following text formatting elements somewhere in the paragraphs:

- `<b>`
- `<i>`
- `<u>`
- `<mark>`
- `<strong>`
- `<em>`

---

# 4. Favorite Websites Section

Create a section titled:

```text
Useful Websites
```

Requirements:

- Add at least 3 clickable links.
- Use an unordered list.

Example websites:

- GitHub
- YouTube
- AWS
- Wikipedia
- W3Schools
- These are just examples...you can include your own favourites.

---

# 5. Image Gallery Section

Create a section titled:

```text
Image Gallery
```

Requirements:

- Add at least 2 images.
- Each image must contain:
  - `src`
  - `alt`
  - `width`
  - `height`

- Add a short caption below each image using paragraphs.

---

# 6. Skills Section

Create a section titled:

```text
My Skills
```

Requirements:

- Use:
  - Ordered list
  - Unordered list

Example skills:

- HTML
- Networking
- Cybersecurity
- Malware Analysis
- Linux

---

# 7. Timetable/Table Section

Create a section titled:

```text
Weekly Study Timetable
```

Create a table containing:

- Days of the week
- Subject/Activity
- Time

Requirements:

- Minimum 4 rows
- Use:
  - `<table>`
  - `<tr>`
  - `<th>`
  - `<td>`

---

# 8. Contact Form Section

Create a section titled:

```text
Contact Me
```

Add a google map of an location at this section.

---

# 9. Footer Section

At the bottom of the webpage:

- Add a horizontal line
- Add copyright information
- Add the current year

Example:

```text
© 2026 Student Portfolio
```

---

# Mandatory Requirements

Your webpage must include:

- Proper HTML structure
- Headings
- Paragraphs
- Formatting elements
- Lists
- Links
- Images
- Tables
- Footer

Save the file as:

```bash
portfolio.html
```

---

# Bonus Challenge (Optional)

Add any of the following:

- Background color using inline styling
- Embedded YouTube video using iframe

---

# Submission Instructions

Submit:

```bash
portfolio.html
```

Ensure:

- The page opens correctly in a browser
- All links work
- Images display properly
- The form appears correctly
