JAVASCRIPT BASICS

1. Variables and Data Types

In JavaScript, you can declare variables using var, let, or const. JavaScript supports various data types including:

  • String: A sequence of characters, e.g., "Hello, World!".
  • Number: Represents both integer and floating-point numbers, e.g., 42 or 3.14.
  • Boolean: Represents logical values, either true or false.
  • Object: A collection of key-value pairs, e.g., { name: "Alice", age: 30 }.
  • Array: An ordered list of values, e.g., [1, 2, 3].
  • Null: Represents the intentional absence of any object value.
  • Undefined: Indicates that a variable has not been assigned a value.

2. Functions

Functions are reusable blocks of code that perform a specific task. You can define a function using the function keyword or as an arrow function. For example:

        // Function declaration
            function greet(name) {
                return "Hello, " + name + "!";
            }   
        // Arrow function
            const greet = (name) => {
                return "Hello, " + name + "!";
            };
        // Using the function
            console.log(greet("Alice")); // Output: Hello, Alice!

3. Control Structures

JavaScript provides various control structures to manage the flow of your code:

  • If-else statements: Used for conditional execution of code blocks.
  • Switch statements: Used for multiple conditions based on a single expression.
  • Loops: Used to execute a block of code repeatedly. Common loops include for, while, and do-while.

4. Events

Events are actions that occur in the browser, such as clicks, mouse movements, or keyboard input. You can handle events using event listeners. For example:

        // Adding an event listener to a button
            const button = document.getElementById("myButton");
            button.addEventListener("click", () => {
                alert("Button was clicked!");
            });
